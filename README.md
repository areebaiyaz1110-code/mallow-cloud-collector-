## 🌙 Project Overview

**Mallow — The Cloud Collector** is an immersive, single-page website built for the **Baby's First Website** hackathon. It invites visitors into a floating pastel sky world, where they meet **Mallow**, an original baby cloud character who is shy, gentle, and endlessly imaginative.

Mallow collects drifting clouds and discovers the **forgotten dreams** tucked inside them, then transforms those dreams into small, delightful experiences. Visitors can explore three interactive showcase projects, scroll through Mallow's origin story, flip between day and night, and hunt for a hidden Easter egg.

> Soft colors. Slow motion. Small surprises. ☁️✨

---

## 💭 Inspiration & Story

Every night, people drift off to sleep and dream. By morning, most of those dreams are gone: a half-remembered melody, a flying staircase, a talking teapot. Where do they go?

Mallow believes they float up and **hide inside clouds**.

Mallow is a baby cloud, a bit too shy to join the big storm clouds and a bit too curious to stay hidden. One quiet evening, while drifting alone, Mallow brushed against a sleepy cloud and heard a faint, forgotten lullaby inside it. From that moment, Mallow began **collecting clouds**, gently unwrapping the dreams inside, and turning them into comforting things for everyone to enjoy.

The website tells this story through a scrolling origin narrative, framing a small child's wonder, a gentle character, and a world that feels like a soft blanket.

## 🎈 Showcase Projects

Mallow's three showcase projects each transform a piece of cloud-collected magic into something interactive.

### 1. 🛏️ Cloud Pillow Factory
Turns fluffy clouds into pillows filled with happy dreams. Visitors interact with the factory to watch a cloud become a cozy, dream-filled pillow.

### 2. 🌧️ Rainy-Day Sound Machine
Creates gentle rainy-day sounds for a calm, cozy atmosphere. Sound is generated in the browser with the **Web Audio API**, with no external audio files required, and starts only after a visitor interacts with the page.

### 3. 🔮 Dream Forecast Station
Generates playful, **fictional** dream forecasts, such as the chance of flying dreams or a light shower of giggles. The forecasts are purely for fun and have no connection to real weather or science.

| Project | Core Idea | Interaction | Tech Highlights |
|---|---|---|---|
| Cloud Pillow Factory | Clouds → dream pillows | Click / tap to make a pillow | React state, CSS animation, `canvas-confetti` |
| Rainy-Day Sound Machine | Gentle rain ambience | Toggle and adjust sound | Web Audio API, `lucide-react` icons |
| Dream Forecast Station | Playful dream forecasts | Press a button for a forecast | React state, CSS transitions |

## 🗺️ Website Structure & User Experience

The site is a single, smoothly scrolling experience, organized into the following sections:

| Section | What the Visitor Experiences |
|---|---|
| 🌅 **Hero** | Mallow floats into view with a gentle greeting and a floating sky backdrop. |
| 🎪 **Showcase Projects** | Three interactive cards invite visitors to play with Mallow's creations. |
| 📜 **Origin Story** | A scrolling narrative explains how Mallow discovered forgotten dreams. |
| 🌗 **Theme Toggle** | A day/night switch changes the sky, colors, and mood. |
| 🥚 **Secret Cloud** | A hidden cloud rewards persistent explorers with a rainbow. |
| 🌙 **Footer** | A quiet sign-off and credits. |

### UX Principles
- **Gentle by default:** slow, soft animations that never feel overwhelming.
- **Playful discovery:** hidden surprises reward curiosity.
- **Responsive:** layouts adapt for desktop and mobile.
- **Considerate audio:** sound plays only when a visitor chooses to start it.

## 🚀 Installation & Local Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (a current LTS version is recommended)
- npm (included with Node.js)
- Git

### Steps

```bash
# 1. Clone the repository
git clone <YOUR_REPOSITORY_URL>

# 2. Move into the project directory
cd <YOUR_PROJECT_FOLDER>

# 3. Install dependencies
npm install
```

> 🔁 **Replace** `<YOUR_REPOSITORY_URL>` and `<YOUR_PROJECT_FOLDER>` with your own values.

<details>
<summary>🌱 Starting from scratch instead?</summary>

```bash
npm create vite@latest mallow-cloud-collector -- --template react
cd mallow-cloud-collector
npm install
npm install lucide-react canvas-confetti
```

</details>
